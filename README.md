# eduardteodor.co.uk
This is the repository for the API for [eduardteodor.co.uk](https://www.eduardteodor.co.uk). The purpose of this repository is to be the source of truth for all information available.

This is part of a bigger collection of prepositories that build my personal ecosystem.
- [eduardteodor-web](https://github.com/EEEDWARD1/eduardteodor-web)
- [eduardteodor-api](https://github.com/EEEDWARD1/eduardteodor-api) ← You are here!
- [eduardteodor-cms](https://github.com/EEEDWARD1/eduardteodor-cms)
- [eduardteodor-db](https://github.com/EEEDWARD1/eduardteodor-db)

## Local Running
For local shell sessions:
```shell
export ConnectionStrings__Database='Host=localhost;Port=5432;Database=your-database;Username=local;Password=your-local-password'
```
